# Picture library folder

Copy any pictures (JPG, PNG, GIF, WebP, AVIF) into this folder, then open
**Appearance → Over The Ball → Pictures**, choose
"Over The Ball: assets/images/library folder" and click **Import**.

They are copied into the Media Library, added to the theme's picture
library, used to fill empty image slots (homepage hero, promo, about,
title banner) and shown in the homepage picture gallery.

On activation the theme also imports every picture from the previously
active theme automatically, so pictures do not need to be copied here
unless they live somewhere else.
